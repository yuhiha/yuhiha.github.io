01들어 있는 것

  1. 주변 모델 숨기기 — 천장만 남겨 보고 같은 키로 다시 보기 (Hide Rest of Model)
  2. 천장 뒤집기 — 컴포넌트 복사본을 스케일 -1로 뒤집어 조명 배치
  3. 다운라이트 중심 표시 — 뒷면 원에 Find Center로 가이드점 만들기
  4. 광원 한 번에 넣기 — 제자리 붙여넣기로 같은 컴포넌트 전체에 렌더링 조명 적용

라탄 의자를 예시로, AI에 가구 모델을 요청할 때 직접 만들어야 할 3D 형상과 재질로 옮길 표면 디테일을 나누는 방법이에요. 복사해서 쓰는 프롬프트는 이 페이지에 있고, 비교용 SKP 두 개는 아래에서 받을 수 있어요.

예제 SKP 받기ZIP · 5.3MB · SketchUp 2026 파일

PC에서 받아 주세요. SKP는 SketchUp 2026 이상에서 열려요. 프롬프트는 휴대폰에서도 바로 복사할 수 있어요.

01생성 전에 무엇을 남길지 정해요

구분3D 형상으로재질로
외곽 형태멀리서도 윤곽을 바꾸는 프레임, 팔걸이, 다리, 좌판외곽 변화가 거의 없는 직조나 인쇄 무늬
두께와 접점쿠션 두께, 바닥에 닿는 다리, 실제로 떨어져 있는 부재표면 안에서만 보이는 결이나 미세한 굴곡
반복 디테일가까이 보는 컷에서 실제 틈이나 단면이 중요한 부분공간 전체 컷에서 무늬로 읽히는 라탄, 직물, 나뭇결

이 예제에서는 앞다리부터 팔걸이와 등받이 상단까지 이어지는 곡선을 형상으로 남겨요. 라탄이 있던 부분은 외곽을 따라 하나의 곡면으로 만들고, 짜임은 재질로 표현해요.

02라탄 의자용 복사 프롬프트

첨부한 참고 이미지를 바탕으로 실내 가구 배치에 사용할 라탄 배럴 체어의 3D 모델을 만들어줘.

[용도]
실내 전체 장면에서 여러 번 배치할 가구 자산이야. 전체 실루엣과 조립 관계가 읽히도록 하고, 반복되는 표면 디테일은 간단히 처리해줘.

[3D 형상으로 만들 부분]
- 양쪽 앞다리에서 팔걸이와 등받이 상단으로 이어지는 검은 프레임을 하나의 연속된 곡선으로 만들어줘.
- 팔걸이에서 등받이로 넘어가는 부분은 넓고 부드럽게 휘게 해줘. 연결부에 별도의 막대를 덧붙이거나 프레임을 겹치지 마.
- 뒷다리의 위치와 벌어지는 각도, 좌판의 윤곽과 쿠션 두께를 유지해줘.
- 라탄이 들어갈 등받이 부분은 프레임 안쪽 외곽을 따라 부드럽게 휘는 하나의 곡면으로 만들어줘.

[재질로 표현할 부분]
- 반복되는 라탄의 짜임, 가닥의 미세한 굴곡, 표면의 반사 차이는 재질로 표현할 수 있도록 준비해줘.
- 등받이를 다른 부재와 따로 선택하고 교체할 수 있게 별도 재질 영역으로 지정해줘.
- 등받이의 UV가 겹치거나 갑자기 늘어나지 않도록 정리해줘.
- 이 모델에서 라탄 가닥 하나하나를 별도 메시로 만들거나 곡면 위에 반복 생성하지 마.

[검수 기준]
- 정면, 사선, 옆면에서 프레임 연결과 전체 윤곽을 확인해줘.
- 등받이 재질을 끈 상태에서도 외곽 형태와 쿠션 두께가 남아 있어야 해.
- 내보내기 전에 등받이 메시를 확인해서 가닥 단위의 반복 형상이 남아 있으면 정리해줘.

03다른 가구에도 쓰는 양식

[ ] 안만 내 가구에 맞게 바꿔서 쓰세요.

참고 이미지의 [가구 이름]을 [배치용 / 제품 근접 컷 / 공간 렌더용] 3D 모델로 만들어줘.

1. 유지할 구조
   [실루엣을 결정하는 부재]를 직접 모델링해줘.
   [두께, 접점, 비례]는 이미지의 인상을 유지해줘.

2. 재질로 처리할 부분
   [반복되는 무늬와 미세한 굴곡]은 별도의 재질로 적용할 수 있게 해줘.
   해당 면을 따로 선택할 수 있도록 재질 영역을 분리하고 UV를 정리해줘.

3. 줄일 형상
   [공간 전체 컷에서 거의 보이지 않는 디테일]을 반복 형상으로 만들지 마.
   [멀리서도 보이는 외곽이나 실제 틈]은 남겨줘.

4. 사용하기 전 확인
   [정면·옆면·사선]에서 윤곽이 유지되는지 보여줘.
   모델을 회전하면서 위치, 단위, 바닥과 닿는 점을 확인할 수 있게 해줘.

04결과가 예상과 다를 때

  • 팔걸이가 두 겹으로 생성됐을 때“앞다리와 등받이 사이를 한 줄의 연속 프레임으로 이어줘. 그 위에 덧대어진 추가 부재는 제거해줘.”
  • 라탄 가닥이 여전히 3D로 남았을 때“등받이 안쪽의 모든 라탄 반복 메시를 제거하고, 기존 외곽을 따라 이어진 곡면과 별도 재질 영역을 남겨줘.”
  • 등받이 모양까지 사라졌을 때“좌우 팔걸이 끝에서 등받이 상단으로 이어지는 기존 외곽선을 기준으로 곡면을 다시 잡아줘.”
  • 무늬가 늘어나 보일 때“곡면 위에서 짜임의 간격이 일정하게 보이도록 UV를 다시 펼치고, 좌우에서 재질 방향을 확인해줘.”

05예제 파일 비교하기

  1. 01_라탄의자_3D짜임.skp를 열고 등받이에서 숨은 형상을 켜요. 가닥마다 보이는 선과 면을 확인해요.
  2. 02_라탄의자_경량화_곡면.skp를 열고 같은 각도에서 등받이를 확인해요. 원하는 Base Color와 Normal 맵을 곡면에 적용해 보세요.
  3. 가구 외곽과 바닥 접점이 유지되는지, 곡면이 프레임 안쪽을 따라가는지 확인해요.
  4. 같은 카메라·조명에서 컬러 맵만 적용한 컷과 노멀 맵을 추가한 컷을 비교해 보세요.

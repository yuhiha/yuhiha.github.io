PC에서 받아 주세요. 라이브러리는 279MB로 용량이 커서 와이파이 환경의 PC에서 받는 걸 권해요. 폰이라면 아래 '링크 복사'로 카톡 '나에게 보내기'에 보낸 뒤 PC에서 열어 주세요.

인스타 안에서 받기가 안 되면 오른쪽 위 ⋯ → 외부 브라우저로 열기를 눌러 주세요.

제품 모델은 제조사 사진·도면을 참고해 저희가 다시 만든 시각화용 모델이에요. 제조사가 배포한 정품 파일이 아니라서 실제 치수는 시공 전에 제조사 자료로 꼭 확인해 주세요.

02쓰는 법

  1. 라이브러리: 파일을 연 뒤 필요한 모델을 골라 복사(Ctrl+C) → 내 모델에서 붙여넣기(Ctrl+V) 하세요. 재질도 같이 따라와요.
  2. 단축키: 압축을 풀고 스케치업 창(Window) → 환경설정(Preferences) → 바로 가기(Shortcuts) → 가져오기(Import)에서 .dat 파일을 고르세요. 기존 단축키가 바뀌니, 필요하면 먼저 '내보내기(Export)'로 지금 설정을 저장해 두세요.
  3. 단축키 일부는 확장 프로그램(Enscape, Fredo Tools, Weld, FixIt 등)이 설치되어 있어야 동작해요.

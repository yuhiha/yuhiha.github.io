유희하 아파트 스케치업 소스

아파트 인테리어를 모델링할 때 매번 새로 그리기 번거로운 창호, 문, 욕실·주방 기구, 천장 설비를 한 파일에 정리했어요. 필요한 것만 복사해서 내 모델에 붙여 쓰시면 돼요.

스케치업 파일 받기SKP · 13MB · 스케치업 2021 이상

PC 스케치업에서 여는 파일이에요. 폰에서는 열리지 않으니, 아래 '링크 복사'로 카톡 '나에게 보내기'에 보낸 뒤 PC에서 받아 주세요.

인스타 안에서 받기가 안 되면 오른쪽 위 ⋯ → 외부 브라우저로 열기를 눌러 주세요.

02쓰는 법

  • 파일을 연 뒤 필요한 소스를 골라 복사(Ctrl+C) → 내 모델에서 붙여넣기(Ctrl+V) 하세요. 재질도 같이 따라와요.
  • 단위는 mm예요. 재질 이름은 '욕실 거울_진회색'처럼 부위_색으로 정리해 두어서 재질 창에서 찾기 쉬워요.
  • 창호는 크기를 숫자로 바꿀 수 있어요. 오른쪽 클릭 → Dynamic Components → Component Options에서 폭·높이를 바꾸세요.
  • 스케치업 2020 이하 버전에서는 열리지 않아요.
